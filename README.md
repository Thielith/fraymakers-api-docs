# Fraymakers API Docs
An unofficial searchable docs page for Fraymakers.

# Hosting Locally
1. Run `git submodule update --init --recursive` to get the data from the linked repositories.
2. Run `make`
3. Run `npm run docs:dev`
4. Go to the local website link displayed in the terminal.

To see any changes you make, redo steps 2 and 3.
